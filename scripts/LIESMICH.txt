AnyPS5 Launcher (Windows)
=========================

1) Start AnyPS5Launcher.exe  (or Start-AnyPS5.cmd)

In the browser launcher:
  Setup  → Install / repair everything  (admin dialog if needed)
  Build  → Full Rebuild
  Convert → pick game folder → Convert → Start

AnyPS5 source is cloned into an "AnyPS5" folder next to the exe
(where you run the launcher from), unless you change the path in Setup.

English UI. Leave the launcher window open while using it.
