AnyPS5 Launcher (Windows)
=========================

1. Start AnyPS5Launcher.exe  (or Start-AnyPS5.cmd)
2. Setup  ->  Install / repair everything
3. Build  ->  Full Rebuild
4. Convert  ->  choose game folder  ->  Convert  ->  Start

AnyPS5 is cloned into an "AnyPS5" folder next to the exe.

Leave the launcher window open while using the UI.
English UI.
