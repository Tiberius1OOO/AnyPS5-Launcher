Why administrator access may be needed

Installing Git, Python, or CMake usually writes into Program Files. WinLibs is extracted under C:\winlibs. winget package installs often require elevation. The launcher itself does not need admin to run.

  • Git / Python / CMake → Program Files
  • WinLibs GCC → C:\winlibs
  • winget install often needs UAC
